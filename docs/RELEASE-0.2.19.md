# Primio 0.2.19 Preview — Collections, plugins and fonts

- My List uses one collection dropdown with title counts and clear Create/Edit controls. Its total count is vertically centered beside the heading. Collection deletion now has a red **Delete** label.
- Automatic collections include titles from My List using readable IF / AND / OR conditions, three presets and a live preview. Rules support up to six groups of eight conditions, manual additions, explicit exclusions and three ordered sort priorities.
- Sort by addition, name, viewing status, rating, year or runtime. Missing numeric metadata stays at the end in either direction; a missing value does not satisfy a negative rule.
- Explore's sort menu floats over the results. Continue watching titles stay on one line, and recommendations stay visible while refreshing with at most two reference titles in their explanation.
- Interface and subtitle settings offer Inter, Manrope, Nunito Sans, Lora and JetBrains Mono, plus imported TTF/OTF fonts. Built-in font choices and collection rules follow the profile sync; imported files and their selection stay on the device. Imports accept up to 5 MB per file and ten distinct fonts.
- OLED color settings now have an explicit Save action. The saved accent colors buttons, borders, icons and active navigation; dark accents receive a readable icon tint. Changes stay in the preview until saved.
- Primio Plugins opens on installed extensions. The header store icon opens the catalog, and Configure opens a modal with Save and Cancel, including the built-in intro skipper. Changes remain in a draft until saved; Cancel, the close icon, Escape and system Back discard the draft.
- Viewing guides create editable collections in My List, with missing titles added and no duplicates. Chronology is selected by default when available. Collections survive plugin removal and follow the profile; deleted collections are not recreated on launch. The supplied Star Wars guide now includes thirteen films, following the [official chronological guide](https://www.starwars.com/news/star-wars-movies-and-series-guide), with release order available too.
- Anime classification includes Japanese, Korean and Chinese animation, with country and original-language variants, localized animation genres and animated films. The original-language fallback applies when the origin is unknown; a Japanese dub alone does not recategorize a known non-Asian production. Random discovery uses the same classification.

Validation: 156 client tests in 26 files, 5 SDK tests, 13 Rust tests, 17 API tests on an isolated SQLite test database, 3 site tests, TypeScript/Vite build and API typecheck. Responsive browser checks passed at 390×844, 1024×900 and 1440×900; all 46 captures were reviewed, including a favorable independent finish review. Save, Cancel, close/Escape, persistence, watch collections and OLED color application were checked.

The final universal Android APK was signed, installed and launched on Medium Primio, preserving the existing library; v2/v3 signing and 16 KB ZIP alignment were verified. Installed plugins, the configuration modal and system Back were explored on the emulator. The final Windows installer was installed and launched; all five bundled fonts loaded in WebView2, native font preparation produced matching files, and interface font import/removal worked. Native player controls are unchanged. These checks do not establish subtitle rendering within arbitrary native videos, physical Android device compatibility or support for every provider stream. The Windows preview installer remains unsigned.

The bundled font licenses are included beside the assets. Application and SDK sources are public; backend and website stay private.
